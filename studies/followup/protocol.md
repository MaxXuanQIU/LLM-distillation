# Three follow-up experiments

The reference study is archived at `8fbc363`. All work uses GPUs 0–3, the original student and teacher snapshots, seed 20261117, the original 5,000 prompts and 200 validation answers, and the 16,384-token response ceiling. Each training arm starts from the original student.

1. On all 400 ARC questions, rotate the choices cyclically through every possible position and score the next-token letter with the original evaluator. Carry the answer key with its content. Score all six existing checkpoints, including the teacher. The primary outcome is accuracy averaged first over rotations per question, then over questions. Report the original-order result, percentage of questions with the same predicted content across all rotations, frequency of choosing A, and the change in each trained-minus-original gap after position averaging. Rotation zero is a reproduction check against the saved predictions.
2. Train off-policy forward KL at peak learning rates 1e-5 and 3e-6. Fix all other settings, including example order, the warmup and cosine schedule over 157 updates. Save student weights and teacher-response validation cross-entropy at updates 32, 80 and 157 for both rates. Record the first sampled update where a benchmark decline is observed. Screen all six checkpoints using identical prompts and batches. Select the highest micro-averaged strict instruction accuracy, then fewest capped answers, then earliest step, then lower learning rate. On the remaining prompts compare the selected checkpoint with the original student and the 1e-5 step-157 reference. If the reference wins screening, report that fact and the strongest distinct candidate as the challenger.
3. Replay exactly the first 32 recorded E4 updates, including all 1,024 answers, in their original order. Use the original 157-step learning-rate schedule for this prefix and peak LR 1e-5. For each logical update compare sum of token KL divided by the total response tokens with an arithmetic mean of each answer's mean token KL. This keeps the trajectories, teachers, batch packing, initialization and optimizer fixed. Confirm both arms on the remaining prompts. This measures a loss-weighting effect on saved contexts. Fresh on-policy training is a different intervention.

For IFEval, select the 64 IDs with the lowest SHA-256 of the fixed string `followup-screen-v1/` followed by the prompt ID. Within each partition use source order, shared batches of 16, greedy decoding, and the original strict scorer. Run the original student with the same batching. The other 477 items are held out from checkpoint selection, although the parent study previously evaluated these benchmark items. Primary outcome is strict instruction accuracy. Also report strict prompt accuracy, cap rate, held-out teacher-response CE and standard and position-averaged ARC accuracy. ARC is secondary in the training experiments and plays no part in selection. Use 10,000 paired bootstrap resamples of questions or whole prompts, keeping rotations and instruction clusters together, with unadjusted percentile intervals. One training seed.
